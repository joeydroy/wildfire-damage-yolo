# Wildfire Damage Classification Using Sentinel-2 and YOLO

## Project Overview
This project uses Google Earth Engine and deep learning to classify residential wildfire damage using Sentinel-2 multispectral imagery.

## Study Areas
- Camp Fire (2018)
- Marshall Fire (2021)
- Maui Fires (2023)

## Methods
- Sentinel-2 preprocessing in Google Earth Engine
- Patch-based dataset creation
- YOLO / classification models
- RGB vs multispectral comparison

## Tools
- Google Earth Engine
- Google Colab
- Python (PyTorch / YOLOv8)
- GeoPandas / Rasterio
