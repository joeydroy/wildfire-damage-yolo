# Multispectral Wildfire Severity Classification Using Sentinel-2 and Patch-Based Machine Learning

## Project Overview
Through Sentinel-2 multispectral imagery, the study will use Google Earth Engine preprocessing with Google Colab Python machine learning to identify wildfire severity patterns across multiple events.
This will automate the severity assessment through spectral indices and patch-based images to classify damage types (High, Moderate, None), with the focus on reproducibility.

## Reseach Goals
Can multispectral Sentinel-2 imagery improve automated wildfire severity classification compared to RGB imagery using patch based machine learning techniques?
How transferable is the classification workflow across multiple event?

## Study Areas
These areas were selected due to their varied geography and land cover.
- Camp Fire (2018)
- Marshall Fire (2021)
- Maui Fires (2023)

## Methods
1. Sentinel-2 preprocessing in Google Earth Engine
2. Patch-based dataset creation
3. Automated severity labeling
4. Machine Learning classification
